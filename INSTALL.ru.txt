ZYN-DICT — автономная установка

Полный сетап на Google Drive:
https://drive.google.com/file/d/1zW7d_2Nxkb35j_-8pgrA1i3qsbd1WnJR/view?usp=drive_link

Распакуйте ZYN-DICT-Setup.rar. Все четыре файла в одной папке:

  ZYN-DICT-Setup-1.0.0-x64.exe
  ZYN-DICT-Setup-1.0.0-x64-1.bin
  ZYN-DICT-Setup-1.0.0-x64-2.bin
  ZYN-DICT-Setup-1.0.0-x64-3.bin

Не переименовывайте файлы. Один .exe без трёх .bin — неполный пакет.
После скачивания интернет для установки не нужен.

Система: Windows 10 версии 1809 или новее / Windows 11, x64.
Windows 7 этой версией приложения не поддерживается.
Установщик нативный: .NET, Python и WebView2 для его запуска не нужны.
Библиотеки приложения и локальные модели уже включены в комплект.

По умолчанию: C:\Program Files\ZYN-DICT.
Можно выбрать другой доступный диск и папку кнопкой «Обзор».
Нужно около 9,4 ГиБ свободного места для программы, рабочих моделей
и локальной резервной копии моделей для восстановления без интернета.

Настройки: <папка установки>\data\settings.json.
Рабочие модели: <папка установки>\models.
Резерв моделей: <папка установки>\data\dependency_payload.
Настройки сохраняются при обновлении и удалении программы.
Удаление: «Установленные приложения» Windows или unins000.exe в папке программы.

В конце установки можно запустить приложение. При запуске анимированная
заставка сопровождает проверку и загрузку моделей.

Установщик пока не подписан сертификатом издателя.
